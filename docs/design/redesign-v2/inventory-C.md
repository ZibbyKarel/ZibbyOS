# Redesign v2 inventory C: Seznamy (lists), Settings, Brand

Read-only inventory. Mockups (third-party, data only) in `design/redesign-v2/project/`: `Seznamy.dc.html`, `Settings.dc.html`, `Brand.dc.html` (+ `bridge.css`; Seznamy and Settings use only `bridge.css`, they do not load `detail.css`/`entity.css`). All three are Czech, dark+light with a theme switch. Gap ids: `C-SZ-NN` (Seznamy), `C-ST-NN` (Settings), `C-BR-NN` (Brand).

Cross-cutting observation: the three mockups draw three different top-nav tracks. Seznamy shows 6 sections (Mustek, Prace, Aktivita, Organizace, Pracovnici, System), Settings shows 6 (Dashboard, Work, Portfolio, Workforce, Knowledge, Governance), the app has 8 (`apps/web/state/config.ts` `SECTIONS`: dashboard, work, companies, workforce, activity, knowledge, governance, system). The chrome was already implemented from `Top Chrome.dc.html`; treat the nav in these mockups as illustrative, do not re-derive nav from them. Exception: Settings is explicitly NOT in the section track in the mockup (see C-ST-01).

## 1. SEZNAMY (lists)

### 1.1 What the mockup shows

Page switcher (11 views) x state switcher (4: Naplneno / Prazdne / Nacitani / Hover-vyber) x device (Obojí / Desktop / Telefon) x theme (dark/light). Each of the 10 list pages is rendered as a desktop frame + a phone frame (390px, 9:41 status bar, app bar with back / section name / round "+" button). The 11th view, "Rodina" (overview), is a design-rationale board (per-page "what is the live signal / what is the silhouette / why this card size" text plus a comparison grid), not an app page.

Shared page frame (`ls-*`): top bar (brand, 6-section nav, search "Hledat nebo spustit... Cmd+K", avatar), page header with breadcrumb `Section / /route`, `h1` 26px, one count line with live counts coloured (violet = running, amber = waits for you), optional extra header buttons, primary "+ New" button (ink). Below: filter bar (search input + count chips, first chip pressed) when the page has `q`/`chips`, then body. Empty state: icon + title + 1-2 sentence explanation + primary CTA + secondary CTA (e.g. "Importovat z GitHub organizace"). Loading: per-card skeleton shaped like the real card. Hover/select state: highlighted card with an "Otevrit" link.
