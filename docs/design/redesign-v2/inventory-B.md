Read-only inventory. Mockups in `design/redesign-v2/project/` (`Agent Detail`, `Goal Detail`, `Entity Detail` `.dc.html`, CSS `bridge.css`, `detail.css`, `entity.css`). ## 1. Agent detail (page prefix `AG`)

### 1.1 Mockup

Views (5): Profile, Used in and runs, New agent, States, Phone.

- **Header band (`ag-hero`)**: 64px avatar with engine mark, `h1` display name + file name small (`reviewer.agent.md`), sub line (role, department link, Enabled dot), exactly 3 chips (model, thinking, engine). Actions: Run, Duplicate, Delete, Save (shows Cmd+S, disabled "Saved" when clean).
- **Context bar**: breadcrumb (Agents > Reviewer), pin button, "More" menu (open file, history, export).
- **Main column**: Instructions card = markdown editor (line numbers, Markdown/Preview toggle, "Frontmatter" read-only toggle, expand, footer with char/word count and hint "/ skills, @ files", note that frontmatter is generated from the right-hand settings).
- **Sticky right column, 4 cards**: Identity (name/file id, display name, role, category, department, icon picker, Enabled switch); When to use (routing text, counter `n / 512`, overflow error); Engine and model (model tier haiku/sonnet/opus/fable, thinking low/medium/high, engine Global/Claude Code/opencode, exact model, inherited-global hint); Tools (chips read/write/bash/git/web, "Advanced" disclosure: optional MCP tools, plugins, risk low/med/high, requires-approval switch).
- **Tabs below** (counts): Rules (3-layer stack: System read-only, From catalog with "tightened below" strike-through and "Link from catalog", Own rules with edit/delete; allow/ask/deny legend), Used in workflows (cards with mini phase graph, agent phase highlighted, runs/pass%/avg cost/avg time + sparkline, link opens workflow at phase), Runs and stats (5 KPI tiles with sparklines: runs 30d, success rate, avg cost, avg duration, spend 30d; table of latest runs with verdict).
- **New agent** is a page (`/workforce/agents/new`), same layout, defaults prefilled, only Name required, file name derived from display name, inline validation (name taken, routing text 548/512).
- **States**: unsaved-changes floating bar (dot on dirty cards, "3 unsaved changes", Discard/Save), delete confirm dialog listing workflows that will break, operator-token-needed amber inline notice (401 on save, changes kept).
- **Phone**: top bar (back, name, run, more), tabs Instructions / Settings / Rules / Usage, sticky Save.

## 2. Goal detail (page prefix `GL`)

### 2.1 Mockup

Views (6): Working, Parked, Done / history / error, Edit, Create / empty, Phone.

- **Context bar**: breadcrumb Goals > name, pin, **run selector** (popover "Runs of this goal": run #, state dot, date, iterations, cost; picks a past run in place), Edit (becomes Cancel/Save), Stop (while running) or Start / Run again, "More: rename, duplicate, delete".
- **Hero (`gl-hero`)**: state pill (Working / Verifier is judging / Waiting for you / Error / Done / Idle) + "Goal, started today 13:20"; the **objective as big text** (editable textbox in Edit mode); meta tags (project, maker, verifier "fresh - opus - high"); right side: **iteration gauge** (arc 4 of 8, "N left before it parks") and **3 run-budget meters** (Today n/5 runs, This week n/20 runs, This month $ spent / $ cap, amber at >=80%).
- **Loop visual**: two nodes (Maker, Verifier) joined by two curved SVG arrows ("result -> judge", "verdict + feedback -> retry"), the active arrow pulses violet, parked state dashes the lower arc, iteration counter "4 / 8" in the middle. Nodes are the edit surface: click opens a popover (maker: agent or workflow + model; verifier: fresh verifier or an agent, model tier, thinking, pass criteria).
- **Iterations timeline** (newest/oldest toggle, header sum "4 iterations - 10m 30s - $1.08"): per iteration numbered marker, maker one-liner, verifier verdict line (pass / fail / paused / judging), duration + cost, expandable timestamped log.
- **Side column**: Waiting-for-you card (amber, reason, "Note for the next iteration" textarea, Resume / Resume without note / Stop goal), Error notice (what failed, Retry iteration, Switch maker to Claude Code, link to AI engines), Pass criteria card (ticks per criterion from the verifier), Instructions card (to the maker, with @file token), Limits card (iterations, runs per day/week, spend per month, per-iteration avg) with Edit.
- **Create page** `/work/goals/new`: objective, project, maker (agent/workflow + select), verifier card (model tier, thinking, pass criteria one per line), limits card (max iterations stepper, runs/day, runs/week, monthly spend, "when the budget runs out"), maker instructions; right sticky preview (loop + worst case / typical cost). Buttons Cancel, Create, Create and start. Empty state "No runs yet" with Start goal.
- **Phone**: objective first, two meters, Maker <-> Verifier compact row, iterations; parked card replaces timeline.
