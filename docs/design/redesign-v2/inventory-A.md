## Page 1: Autonomy (`Autonomy.dc.html`)

### 1. What the mockup shows

Four views (props `view`: header, levels, phone, notes), dark and light theme toggle each.

- **Hlavicka a rezimy (header)**: Top Chrome with a new "Zibby" section: orb button (opens chat, Cmd+J) plus a mode button (Manual / Poloautomat / Automat). Artboards: live interactive stage (560 px high, simulated flags "Cekajici schvaleni" and "Chybi operatorsky token"), then static stages for Manual (orb `sleep`, section muted grey), Poloautomat (orb `think`, violet section), Automat (orb `speak`, amber section pulsing, amber header underline, amber edge glow around the whole app), then the open mode popover for Poloautomat and Automat. The popover (400 px) has a big orb with one-line meaning, three radio cards (one per mode, each with an orb in its own state), a link "3 schvaleni cekaji na tebe" and a link "Urovne autonomie" listing the exceptions. Switching down is instant; switching to Automat opens a confirm dialog.
- **Confirm dialog "Prepnout Zibbyho na Automat?"**: text, list of exceptions that stay, "Tohle se zepta vzdy" lock panel with chips (Merge, Deploy, Platby, Mazani, Force push, Push do sdilenych vetvi, E-mail, Otevreni PR, Nova issue v Jire), note that pending approvals stay pending, operator token field (password, `zby_op_...`) or "Operatorsky token overen" row. Buttons Zrusit / Prepnout na Automat (disabled without token).
- **Urovne autonomie (levels)**: new page under Governance, tabs Gates | Urovne autonomie | Rozpocty | Utrata. Header with title and a radiogroup "Rezim Zibbyho" mirroring the header mode. A table: rows = Vychozi (global), companies, teams (collapsible per company, "Dedit vse" button per row); columns = three lanes Manual / Poloautomat / Automat (each with orb and one-line lane meaning, lanes above the current mode shown "capped" with note "Ted jako Poloautomat"). Each capability (Code review, Pripominky z review, Implementace, Komunikace, Oprava CI) is a draggable chip in exactly one lane per row; inherited chips are dimmed, own overrides carry a dot. Click opens a menu (three modes + "Dedit z <parent>"), arrow keys move the chip, Implementace cannot go to Automat (toast / disabled menu item). Immediate save with a toast and "Zpet" (undo). Footer: "Vzdy se zepta, v kazdem rezimu" chips.
- **Telefon 390**: four phones: Manual, Poloautomat, Automat (with amber band "Automat . Zibby rizi vse" and "Zmenit" link), and the mode bottom sheet (grabber, big orb, three cards, pending link, levels link). Toolbar shows compact Zibby section (orb + mode name).
- **Model a pravidla (notes/spec)**: result matrix (capability column x header mode), proposed data change (`level: manual|semi|auto`, `automation[scope][cap]: manual|semi|auto`, effective = min(level, cell), migration off->semi, full->auto, toggle true->auto / false->manual), token only for raising to Automat, API rejects `implement: auto`, route `/governance/autonomy`, amber semantics, a11y list.

### 1. What the mockup shows
